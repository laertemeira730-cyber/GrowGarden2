# GrowGarden2 — Minecraft Forge 1.20.1

Projeto-fonte do mod GrowGarden2, compilado com Java 17 e Forge 47.2.0.

## Compilação automática
O GitHub Actions executa o workflow **Build GrowGarden2** a cada envio para `main` e também manualmente. Após uma execução bem-sucedida, baixe o JAR na seção **Artifacts** da execução.

## Recursos da versão 0.1.0
- Delimitadores invisíveis para Jardim, Loja e Vendas.
- Dois cantos do mesmo tipo definem uma área retangular horizontal.
- Várias áreas por jogador e tipo, salvas no mundo.
